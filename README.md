# Laporan Keuangan Pribadi

Aplikasi pencatat pemasukan dan pengeluaran. Halaman di GitHub Pages, data di Google Sheets milik sendiri.

- `index.html`: halaman aplikasi
- `config.js`: tempat mengisi URL backend (Apps Script)
- `backend/Code.gs`: salinan kode backend (jalannya di Google Apps Script, bukan di GitHub)

Data keuangan TIDAK disimpan di repository ini. Kata sandi disimpan di Script properties Apps Script, bukan di kode.
